## 方舟服务端到底吃什么：单核、内存、磁盘

**单核频率排第一，核心数排第二。** 方舟的物理、AI、存档写入都在主线程上，多核优化有限。选机器时先看 CPU 型号和主频，再看几核。同一价位下，4 核高频普遍比 8 核低频更适合方舟。

**内存按地图张数算，不是按人数算。** 单张地图 4G 能启动，但服务端会靠内存压缩硬撑，建筑一多就开始卡；6G 以上才算稳定。2～4 人单图，4 核 8G 够；6 人以上大地图，建议 4 核 16G；想开“几通”（同一台机器跑多张互通地图），一张图按 4～6G 往上加，11 通至少 64G。

**磁盘留够，这是最容易被忽略的一项。** 服务端本体体积在两个口径之间差距很大：Linux 端纯净本体大约 15G，而完整下载含全部资源可能到 60G。加上几个大 MOD 轻松突破 25G，再算上存档和备份，**预留 60～100G 的 SSD 更稳**。机械盘会在保存世界的那几秒把读写打满，全服一起卡。雨云游戏云 NAT 版起步是 30GB 系统盘加 20GB 数据盘，合计 50GB，装方舟本体够，装完 MOD 就紧张，下单时把数据盘加上去比事后迁移省事。

**带宽需求不高。** 10 人左右的服，上行 5Mbps 通常就够，方舟的流量集中在进服和区域加载的瞬间。比起带宽大小，线路稳不稳更影响体验。

**PVP 服额外看防御。** 公开服容易被扫、被压，带防御的机房省心；纯朋友私服、密码进服，防御优先级可以往后放。

## 端口为什么必须选 UDP：7777、7778、27015 怎么映射

方舟服务端走的是 UDP，这是最容易翻车的一步。在控制台映射端口时选成 TCP，服务端日志一切正常，客户端就是连不上。

| 端口 | 协议 | 用途 |
| --- | --- | --- |
| 7777 | UDP | 游戏主端口，必须 |
| 7778 | UDP | 原始 UDP 通道，必须，和 7777 配套 |
| 27015 | UDP | Steam 查询端口，决定服务器能不能在列表里被搜到 |
| 32330 | UDP | RCON 远程管理，可选 |

关于 27015，网上教程说法不一致：有写 TCP 的，有写 TCP 和 UDP 都要放行的。以较新的教程口径为准，它是 UDP；但如果你的服务商面板或者安全组模板要求 TCP 也放行，两条一起开不会出问题，少开一条则可能刷不出服务器。

**NAT 型服务器能开方舟。** 在端口映射页面按“外部端口 → 内部端口”建三条规则，比如外部 17777 转内部 7777、17778 转 7778、17015 转 27015，然后让朋友连 `你的IP:17777`。记住一条：映射出来的外部端口是几，客户端就填几；启动参数里的 `QueryPort` 也要和映射后的查询端口对上，否则服务器列表里永远刷不出来。

NAT 版通常有端口转发条数上限（雨云的 NAT 游戏云是 15 条），方舟三个端口占三条，开两三张地图也够用。需要建站、需要独立公网 IP、或者要做端口之外的转发，才值得加钱上独立 IP。4 核 8G 这一档，NAT 和独立 IP 的差价大概在七八十元一个月。

## 两条搭建路线：Windows 面板和 Linux 命令行

**不懂命令行的走 Windows + ARK Server Manager。** 这是一套图形化面板，装好后右上角把语言切成简体中文，点绿色加号新建地图，填服务器名、进服密码、管理员密码、端口、最大人数，地图下拉里选孤岛、仙境、畸变、灭绝、创世纪、水晶岛、中心岛、瓦尔盖罗、焦土。规则页里勾上 PVP（不勾默认是 PVE），MOD ID 那一栏填创意工坊链接 `?id=` 后面的数字，多个用英文逗号隔开。面板自带一键备份和定时重启，对新手友好。

**想长期挂着不折腾的走 Linux。** Ubuntu 22.04 或 Debian 12，装依赖、拉 SteamCMD、下载服务端：

bash
sudo apt install -y lib32gcc-s1 curl wget tar screen
mkdir ~/steamcmd && cd ~/steamcmd
wget https://steamcdn-a.akamaihd.net/client/installer/steamcmd_linux.tar.gz
tar xzf steamcmd_linux.tar.gz
./steamcmd.sh +force_install_dir ~/ark +login anonymous +app_update 376030 validate +quit


`376030` 是方舟专用服务端的 App ID，第一次装必须带 `validate`。

启动命令长这样，`?listen` 不能省，省了客户端连不上：

bash
./ShooterGameServer "TheIsland?listen?SessionName=我的方舟服?ServerPassword=123456?ServerAdminPassword=admin666?Port=7777?QueryPort=27015?RCONPort=32330?MaxPlayers=20" -server -log


挂后台用 `screen -S ark`，起来之后按 `Ctrl+A` 再按 `D` 脱离。要更稳就写成 systemd 服务，`Restart=on-failure` 加 `RestartSec=30`，崩了自动拉起、开机自启，适合 24 小时常驻的长期服。

**难度参数改一个就够。** 配置文件在 `ShooterGame/Saved/Config/LinuxServer/GameUserSettings.ini`（Windows 是 `WindowsServer`），`OverrideOfficialDifficulty=5.0` 对应野生龙最高 150 级，公式是难度乘 30。同一文件里还能调经验倍率、驯服速度、采集倍率，以及 `ActiveMods=`。

## Mod、存档、故障：几个必须记住的路径

- **装 MOD**：创意工坊链接里 `?id=` 后面那串数字就是 MOD ID，填进 `ActiveMods=`，用英文逗号分隔，服务端启动时会自动下载。MOD 更新有可能让存档不兼容，更新前先备份。
- **存档位置**：`ShooterGame/Saved/SavedArks`，里面 `.ark` 是世界、`.arktribe` 是部落、`.arkprofile` 是玩家。整个 `Saved` 目录打包就是一份完整备份，配个 crontab 每天凌晨跑一次，顺便删掉七天前的旧包。
- **列表搜不到**：九成是查询端口没映射、协议选错，或者 `QueryPort` 和实际映射对不上。
- **朋友卡在加载界面**：7777 和 7778 要一起映射，只开 7777 是最常见的错误。
- **开服后越跑越卡**：先用 `htop` 看那颗主线程核心是不是长期 100%、内存是不是贴着上限、有没有开始用 swap。内存吃紧就加 swap 应急，长期方案是升内存。定期重启是最有效的土办法。
- **游戏更新后进不去**：停服，重新执行一遍 `app_update 376030 validate`。

方舟到现在还在发更新补丁，服务端不跟着更新，玩家客户端就会版本不匹配。选长期开服，机器最好支持随时重装系统和快速重置。
